| Nome do Caso de Uso | Compartilhar Coleção |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente compartilhe sua coleção para que outros visualizem seus álbuns e itens. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e possuir uma coleção cadastrada. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa a página da sua coleção e seleciona a opção de 'Compartilhar'. |  |
|  | 2. O sistema gera um link de compartilhamento e exibe opções de redes sociais. |
| 3. O cliente copia o link ou escolhe a rede social desejada. |  |
|  | 4. O sistema confirma que o compartilhamento foi iniciado/gerado. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso a coleção do cliente esteja definida como privada nas configurações, o sistema exibe alerta informando que é necessário torná-la pública primeiro. |
