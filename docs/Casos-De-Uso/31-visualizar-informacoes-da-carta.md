| Nome do Caso de Uso | Visualizar Informações da Carta |

| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e estar na tela de detalhes da carta. |

| Ações do Ator | Ações do Sistema |
|---|---|

|  | 2. O sistema apresenta os dados de identificação da carta (nome, número, coleção, categoria, raridade e idioma). |
| 3. O cliente consulta as informações apresentadas. |  |
