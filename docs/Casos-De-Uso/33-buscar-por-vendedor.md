| Nome do Caso de Uso | Buscar por Vendedor *** |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente busque cartas por vendedor para visualizar os anúncios disponibilizados por um usuário específico. (Funcionalidade futura do Marketplace) |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e estar na tela de pesquisa do marketplace. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente informa o nome ou usuário do vendedor no campo de busca. |  |
|  | 2. O sistema pesquisa os anúncios cadastrados pelo vendedor informado. |
|  | 3. O sistema exibe a lista de anúncios encontrados. |
| 4. O cliente seleciona o anúncio desejado na lista de resultados. |  |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se o sistema não encontrar nenhum vendedor correspondente ao termo buscado, exibe a mensagem 'Nenhum resultado encontrado'. |
