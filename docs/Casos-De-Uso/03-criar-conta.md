| Nome do Caso de Uso | Criar Conta |
|---|---|
| Finalidade/Objetivo | Permitir que o visitante se cadastre informando seus dados básicos, tipo de usuário e aceitando os termos. |
| Atores | Visitante |
| Pré Condições | O visitante deve estar na tela Home ou ter a barra de busca visível. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O visitante seleciona a opção de 'Cadastrar'. |  |
|  | 2. Solicitar o preenchimento dos dados de cadastro e seleção do tipo de usuário. |
| 3. Informar campos solicitados e aceitar os termos de uso. |  |
|  | 4. O sistema valida os campos preenchidos e a disponibilidade do e-mail. |
|  | 5. O sistema registra o usuário no banco de dados e exibe mensagem de sucesso. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso a busca não retorne nenhum resultado, exibir a mensagem 'Nenhum resultado encontrado para o termo pesquisado'. |
