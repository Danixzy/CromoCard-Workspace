| Nome do Caso de Uso | Buscar por Raridade |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente filtre cartas por raridade para encontrar itens com características específicas. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e estar na tela de pesquisa de cartas. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente seleciona a raridade desejada no filtro de busca. |  |
|  | 2. O sistema filtra as cartas que correspondem à raridade selecionada. |
|  | 3. O sistema exibe a lista de cartas encontradas. |
| 4. O cliente seleciona a carta desejada na lista de resultados. |  |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se o sistema não encontrar cartas para a raridade selecionada, exibe a mensagem 'Nenhuma carta encontrada com os termos informados'. |
