| Nome do Caso de Uso | Listar Álbum |
|---|---|
| Finalidade/Objetivo | Exibir de forma organizada todos os álbuns iniciados ou favoritados que pertencem à biblioteca do usuário. |
| Atores | Cliente |
| Pré Condições | O usuário deve estar logado e selecionar a opção 'Meus Álbuns' no menu de navegação. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O usuário clica na opção 'Meus Álbuns' do menu principal. |  |
|  | 2. O sistema exibe um formulário solicitando Título, Editora/Ano e uma descrição opcional. |
|  | 3. O sistema renderiza a lista de álbuns ativos, exibindo a capa de cada um, título e barra de progresso individual. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se o usuário não tiver álbuns adicionados, o sistema apresenta uma tela com uma mensagem informativa e um botão direcionando para o Catálogo Global. |
