| Nome do Caso de Uso | Visualizar Cartas Mais Vendidas |
|---|---|
| Finalidade/Objetivo | Como Vendedor preciso visualizar as cartas mais vendidas para identificar quais produtos possuem maior procura. |
| Atores | Vendedor |
| Pré Condições | O vendedor deve acessar o painel de métricas/dashboard da sua conta. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor acessa o relatório de 'Cartas Mais Vendidas' |  |
|  | 2. O sistema filtra e ordena o histórico de vendas agrupando pelas cartas de maior saída |
|  | 3. O sistema exibe o ranking em formato de lista informando o volume de cada carta |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se não houver dados suficientes no período selecionado (ex: último mês sem vendas), o sistema indica 'Não há dados suficientes para formar o ranking no período escolhido' |
