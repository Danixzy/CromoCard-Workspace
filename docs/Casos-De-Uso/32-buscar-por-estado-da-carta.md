| Nome do Caso de Uso | Buscar por Estado da Carta ** |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente filtre cartas por estado de conservação para encontrar itens de acordo com a condição desejada. (Funcionalidade futura) |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e estar na tela de pesquisa de cartas. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente seleciona o estado de conservação desejado no filtro de busca. |  |
|  | 2. O sistema filtra as cartas que correspondem ao estado de conservação selecionado. |
|  | 3. O sistema exibe a lista de cartas encontradas. |
| 4. O cliente seleciona a carta desejada na lista de resultados. |  |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se o sistema não encontrar cartas para o estado de conservação selecionado, exibe a mensagem 'Nenhuma carta encontrada com os termos informados'. |
