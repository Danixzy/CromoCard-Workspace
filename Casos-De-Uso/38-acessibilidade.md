| Nome do Caso de Uso | Acessibilidade |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso ativar recursos como narrador de tela, modo daltonismo e alto contraste para conseguir navegar, ouvir e visualizar as informações da plataforma com clareza. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar navegando na plataforma e acessar o menu de configurações de acessibilidade. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa o menu de configurações e entra em 'Acessibilidade' |  |
|  | 2. O sistema exibe as opções de Narrador de Tela, Modo Daltonismo e Alto Contraste |
|  | 3. O cliente seleciona e ativa os recursos desejados |
|  | 4. O sistema aplica as alterações visuais de contraste e cores imediatamente na interface |
|  | 5. O sistema ativa o serviço de conversão de texto em áudio para os elementos focados na tela |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente opta por desativar todos os recursos de acessibilidade ativados anteriormente |  |
|  | 2. O sistema restaura o tema visual padrão da plataforma e encerra o narrador de tela |
