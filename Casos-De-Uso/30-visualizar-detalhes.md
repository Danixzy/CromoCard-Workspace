| Nome do Caso de Uso | Visualizar Detalhes |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente visualize os detalhes de uma carta para conhecer suas características antes de realizar uma compra. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e ter localizado a carta através da busca. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente seleciona a carta desejada na lista de resultados. |  |
|  | 2. O sistema carrega e apresenta a tela de detalhes da carta, com suas características, imagens e informações de anúncios disponíveis. |
| 3. O cliente navega pelas informações apresentadas. |  |
