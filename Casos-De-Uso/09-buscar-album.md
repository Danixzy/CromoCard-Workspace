| Nome do Caso de Uso | Buscar Álbum |
|---|---|
| Finalidade/Objetivo | Permitir a filtragem e localização rápida de um álbum específico dentro da biblioteca do usuário através de texto. |
| Atores | Cliente |
| Pré Condições | O usuário deve estar na tela 'Meus Álbuns' com a barra de pesquisa interna visível. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O usuário digita o nome ou ano do álbum no campo de busca interno. |  |
|  | 2. O sistema filtra dinamicamente a listagem de álbuns em tempo real conforme os caracteres são inseridos. |
| 3. O usuário seleciona o álbum desejado nos resultados filtrados. |  |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se o usuário não tiver álbuns adicionados, o sistema apresenta uma tela com uma mensagem informativa e um botão direcionando para o Catálogo Global. |
