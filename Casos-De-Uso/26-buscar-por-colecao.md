| Nome do Caso de Uso | Buscar por Coleção |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente busque cartas pertencentes a uma coleção específica. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e estar na tela de pesquisa de cartas. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente seleciona a coleção desejada no filtro de busca. |  |
|  | 2. O sistema filtra as cartas pertencentes à coleção informada. |
|  | 3. O sistema exibe a lista de cartas encontradas. |
| 4. O cliente seleciona a carta desejada na lista de resultados. |  |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se a coleção selecionada não possuir cartas cadastradas, o sistema exibe a mensagem 'Nenhuma carta encontrada com os termos informados'. |
