| Nome do Caso de Uso | Denunciar Usuario |
|---|---|
| Finalidade/Objetivo | Como Vendedor preciso denunciar usuários para informar comportamentos inadequados à plataforma. |
| Atores | Vendedor |
| Pré Condições | O vendedor deve acessar o perfil ou o chat do usuário comprador. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor acessa a conversa ou o perfil do comprador e seleciona 'Denunciar' |  |
|  | 2. O sistema solicita a categoria da denúncia (ex: spam, linguagem ofensiva) |
| 3. O vendedor preenche os dados necessários e envia |  |
|  | 4. O sistema processa o envio e informa que a moderação irá analisar o caso |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor tenta enviar sem detalhar o comportamento no campo de observação obrigatório |  |
|  | 2. O sistema alerta exigindo uma breve explicação do ocorrido |
