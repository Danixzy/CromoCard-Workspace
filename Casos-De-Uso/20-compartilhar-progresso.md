| Nome do Caso de Uso | Compartilhar Progresso |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente compartilhe o progresso do seu álbum para mostrar a outras pessoas o andamento da sua coleção. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e possuir um álbum com progresso registrado. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa o resumo do álbum e clica na opção 'Compartilhar Progresso'. |  |
|  | 2. O sistema gera uma imagem ou link contendo as estatísticas e percentuais atuais do álbum. |
| 3. O cliente seleciona o meio de compartilhamento (rede social, link direto). |  |
|  | 4. O sistema processa o compartilhamento e exibe mensagem de sucesso. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso o álbum esteja com 0% de progresso, o sistema exibe alerta perguntando se o cliente deseja realmente compartilhar um álbum vazio. |
