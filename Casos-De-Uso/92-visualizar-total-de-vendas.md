| Nome do Caso de Uso | Visualizar Total de Vendas |
|---|---|
| Finalidade/Objetivo | Como Vendedor preciso visualizar o total de vendas para acompanhar a quantidade de negociações realizadas. |
| Atores | Vendedor |
| Pré Condições | O vendedor deve acessar o painel de métricas/dashboard da sua conta. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor acessa a aba de 'Estatísticas' ou 'Dashboard' |  |
|  | 2. O sistema calcula a soma de todas as transações concluídas com sucesso |
|  | 3. O sistema renderiza gráficos e cards numéricos apresentando o total financeiro e volume de vendas |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se for um vendedor iniciante sem vendas, o painel exibirá as métricas zeradas com incentivos para realizar a primeira venda |
