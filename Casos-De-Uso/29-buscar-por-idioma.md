| Nome do Caso de Uso | Buscar por Idioma |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente filtre cartas por idioma para encontrar cartas na língua desejada. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e estar na tela de pesquisa de cartas. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente seleciona o idioma desejado no filtro de busca. |  |
|  | 2. O sistema filtra as cartas disponíveis no idioma selecionado. |
|  | 3. O sistema exibe a lista de cartas encontradas. |
| 4. O cliente seleciona a carta desejada na lista de resultados. |  |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se o sistema não encontrar cartas no idioma selecionado, exibe a mensagem 'Nenhuma carta encontrada com os termos informados'. |
