| Nome do Caso de Uso | Editar Perfil |
|---|---|
| Finalidade/Objetivo | Como Vendedor preciso editar meu perfil para manter minhas informações atualizadas. |
| Atores | Vendedor |
| Pré Condições | O usuário deve estar autenticado e na tela 'Meu Perfil'. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor clica na opção de 'Editar Perfil' |  |
|  | 2. O sistema habilita os campos de dados pessoais, foto, e meios de recebimento |
| 3. O vendedor altera as informações necessárias e clica em 'Salvar' |  |
|  | 4. O sistema valida os dados e atualiza o cadastro no banco de dados |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor insere um e-mail ou documento que já pertence a outra conta |  |
|  | 2. O sistema exibe o erro 'Esta informação já está em uso por outro usuário' |
