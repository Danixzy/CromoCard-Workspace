| Nome do Caso de Uso | Buscar Categoria do Card |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso pesquisar e visualizar os cards através dos seus elementos específicos para encontrar Card exatos dentro da minha coleção. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e acessar a área de busca ou inventário de cards. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente informa os elementos específicos (ex: nome, raridade, atributos) no campo de pesquisa |  |
|  | 2. O sistema valida os parâmetros de busca informados |
|  | 3. O sistema retorna e exibe os cards da coleção que correspondem aos elementos pesquisados |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso nenhum card corresponda aos elementos pesquisados, o sistema apresenta a mensagem 'Nenhum card encontrado com estes elementos' e sugere limpar os filtros |
