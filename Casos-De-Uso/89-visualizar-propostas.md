| Nome do Caso de Uso | Visualizar Propostas |
|---|---|
| Finalidade/Objetivo | Como Vendedor preciso visualizar propostas recebidas para analisar as condições oferecidas pelos compradores. |
| Atores | Vendedor |
| Pré Condições | O vendedor deve ter recebido ao menos uma proposta/oferta em seus anúncios. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor clica no menu de 'Propostas Recebidas' ou notificações |  |
|  | 2. O sistema compila e exibe a lista de propostas ativas contendo valor, data e usuário |
| 3. O vendedor clica sobre uma proposta específica para ver detalhes |  |
|  | 4. O sistema abre a interface de negociação permitindo aceitar ou recusar |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Caso a lista de propostas esteja vazia, o sistema exibe 'Você não tem novas propostas no momento' |
