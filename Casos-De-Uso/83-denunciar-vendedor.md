| Nome do Caso de Uso | Denunciar Vendedor |
|---|---|
| Finalidade/Objetivo | Como Cliente preciso denunciar um vendedor que tenha uma irregularidade dentro da plataforma. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e acessando o perfil público do vendedor. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente acessa o perfil do vendedor e clica em 'Denunciar Vendedor' |  |
|  | 2. O sistema solicita a escolha de um motivo para a infração |
| 3. O cliente escolhe o motivo, descreve a situação e envia |  |
|  | 4. O sistema registra a ocorrência no painel de moderação e avisa o cliente do sucesso |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente cancela a denúncia fechando a janela |  |
|  | 2. O sistema aborta o processo e não envia nenhum dado |
