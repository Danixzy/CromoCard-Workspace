| Nome do Caso de Uso | Gestão de Comunidade |
|---|---|
| Finalidade/Objetivo | Permitir que o administrador gerencie os grupos da comunidade, incluindo criação, alteração e controle dos grupos existentes. |
| Atores | Administrador |
| Pré Condições | O administrador deve estar autenticado e possuir permissão para gerenciar grupos. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O administrador acessa a opção "Gestão de Comunidade". |  |
|  | 2. O sistema apresenta os grupos existentes. |
| 3. O administrador seleciona um grupo ou escolhe criar um novo grupo. |  |
|  | 4. O sistema apresenta as informações e opções disponíveis. |
| 5. O administrador informa ou altera os dados do grupo. |  |
|  | 6. O sistema valida os dados informados. |
| 7. O administrador confirma a operação. |  |
|  | 8. O sistema registra as alterações. |
|  | 9. O sistema atualiza a lista de grupos e confirma a operação. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O administrador tenta criar um grupo com dados inválidos ou incompletos. |  |
|  | 2. O sistema informa os campos que precisam ser corrigidos. |
| 3. O administrador corrige os dados. |  |
|  | 4. O sistema realiza novamente a validação. |
| 5. O administrador cancela a operação. |  |
|  | 6. O sistema cancela a operação sem realizar alterações. |
