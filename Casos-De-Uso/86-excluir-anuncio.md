| Nome do Caso de Uso | Excluir Anúncio |
|---|---|
| Finalidade/Objetivo | Como Vendedor preciso excluir um anúncio para retirar uma carta definitivamente do marketplace. |
| Atores | Vendedor |
| Pré Condições | O vendedor deve ter um anúncio criado (ativo ou pausado). |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor seleciona a opção 'Excluir' no anúncio correspondente |  |
|  | 2. O sistema exibe uma caixa de diálogo pedindo a confirmação da exclusão definitiva |
| 3. O vendedor confirma a exclusão |  |
|  | 4. O sistema remove o anúncio do marketplace e do painel do vendedor |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O vendedor seleciona 'Cancelar' na caixa de diálogo |  |
|  | 2. O sistema fecha o aviso e mantém o anúncio inalterado |
