| Nome do Caso de Uso | Visualizar Cartas |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente visualize as cartas de um álbum para acompanhar os itens da coleção. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado e acessar os detalhes de um álbum. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente seleciona um álbum na plataforma. |  |
|  | 2. O sistema busca as cartas referentes ao álbum selecionado. |
|  | 3. O sistema exibe as cartas em formato de lista ou grade com seus respectivos status. |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se o álbum ainda não possuir cartas mapeadas, o sistema exibe a mensagem 'Nenhuma carta cadastrada para este álbum ainda'. |
