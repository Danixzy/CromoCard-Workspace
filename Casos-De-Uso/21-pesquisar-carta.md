| Nome do Caso de Uso | Pesquisar Carta |
|---|---|
| Finalidade/Objetivo | Permitir que o cliente pesquise uma carta para localizar o item que deseja adicionar à sua coleção. |
| Atores | Cliente |
| Pré Condições | O cliente deve estar autenticado. |

### Fluxo Principal

| Ações do Ator | Ações do Sistema |
|---|---|
| 1. O cliente insere o nome, número ou característica da carta no campo de busca. |  |
|  | 2. O sistema processa a consulta na base de cartas disponíveis. |
|  | 3. O sistema lista os resultados correspondentes aos termos pesquisados. |
| 4. O cliente seleciona a carta desejada a partir dos resultados. |  |

### Fluxo Alternativo

| Ações do Ator | Ações do Sistema |
|---|---|
|  | 1. Se o sistema não encontrar nenhuma correspondência, exibe a mensagem 'Nenhuma carta encontrada com os termos informados'. |
